# multi-agent-travel-planner-

## How to run?? 

1. Creating the virtual enviroment 

```bash
   python -m venv .venv
```

2. Activate the enviroment 

```bash
   # Windows
   .venv\Scripts\activate
   # macOS / Linux
   source .venv/bin/activate
```

3. Install the  requirements

```bash
   pip install -r requirements.txt
```
